# YouthAI Lab — Deliverables

Public deliverables of the YouthAI Lab project.

## What's inside

### `ComprehensiveApproach/` — D2.1
Full programme overview, methodology, and the 6-phase approach. One subfolder per language (EN / FR / IT / CA / NL) with the markdown source and (when available) the published PDF.

### `ExplorationProtocol/`
Exploration sheet protocol + report template used during the workshops. One subfolder per language (EN / FR / IT / CA / NL). The CA subfolder also holds the four day-by-day workshop programmes run by the UAB lab.

### `Paillasses/`
Printable lab-bench sheets, one per phase of the 6-phase approach, plus a combined file with all six. Currently French only (`FR/`).

### `Ideation_Sheets/`
Ideation sheets for the workshop "exploration" activities, as ready-to-use PDFs:
- AI Detectives (UAB)
- Bias Bounty Hunt
- BIAIS
- Bio-Inspired Algorithms
- Illusions
- Introductory AI Game · Predictive AI
- Keep Eye on AI
- Looks Right
- Machine Brain (UAB)
- Make Cities Great Again
- Robot AI Designing (UAB)
- The Stupid Invention
- WikiYouthBot

`WikiYouthBot_Materials/` holds the printable material that goes with the WikiYouthBot sheet: the SDG memorisation sheet, the bingo grids laid out four per page, and the score table.
